# Voices of the Forgotten Machines

A mobile-first React + Vite + Tailwind CSS storytelling app about abandoned NASA equipment on the Moon and Mars.

## Features

- React Router navigation between Home, Choose World, Maps, Story, Timeline, and About pages
- Dark space-themed UI optimized for mobile screens
- Lottie-free, lightweight motion using Framer Motion
- Leaflet map views for moon and mars exploration
- Artifact data stored in a dedicated JSON/JS module
- Responsive cards, narrative sections, and timeline storytelling

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Leaflet + React Leaflet

## Getting Started

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Build for production:
   npm run build

## Project Structure

- `src/components` — reusable UI components
- `src/data` — artifact data and content model
- `src/pages` — route-level pages
- `src/App.jsx` — app layout and routes
- `src/index.css` — Tailwind directives and theme styling

## Notes

This project intentionally avoids official NASA branding and instead focuses on a fictionalized storytelling layer inspired by abandoned equipment on lunar and martian surfaces.
